# Frontier app (Oracle)

Apps generated from [persona-template-frontier-app](https://github.com/persona-id/persona-template-frontier-app)
deploy to Persona's Frontier platform. Stack, dependencies, and commands vary by app.

**Before you install, test, deploy, or change Frontier wiring, read every skill in
[frontier-claude-skill](https://github.com/persona-id/frontier-claude-skill)** —
each `SKILL.md` under `skills/` (`frontier-deploy`, `frontier-oauth`,
`frontier-snowflake`). That repository is the source of truth for platform setup,
CI, local and cluster testing, deployment, auth, and Snowflake access.
